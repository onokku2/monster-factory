# モンスターファクトリー 🧬

ドット絵モンスターを **集める・組む・鍛える・戦う** 育成バトルゲーム。
ビルド不要・完全オフライン。`PLAY.bat` をダブルクリック（または `index.html` をブラウザで開く）するだけで遊べます。

## 🌐 公開URL（恒久・本番）
**https://onokku2.github.io/monster-factory/**
GitHub Pages で常時稼働。スマホでこのURLを開き「ホーム画面に追加」でアプリ化できます。

### 自動デプロイ
リポジトリ `github.com/onokku2/monster-factory`。`main` に push すると GitHub Actions（`.github/workflows/pages.yml`）が自動でビルド＆公開します。
```
git add -A && git commit -m "update" && git push   # → 数十秒後に上記URLへ反映
```

## 📲 スマホアプリ（PWA）として使う

### かんたん公開（アカウント不要・自動）
`DEPLOY.bat` をダブルクリック → コンソールに表示される **`https://〇〇.trycloudflare.com`** をスマホで開く → 「ホーム画面に追加」でアプリ化。
- 内部では「このフォルダをローカル配信＋Cloudflareクイックトンネルで公開」しています（無料・ログイン不要）。
- **一度スマホで開けば Service Worker がアプリ一式をキャッシュ**するので、以後は**トンネルやPCを切ってもオフラインで起動**します。
- 注意：trycloudflare の無料URLは一時的（PC＆`DEPLOY.bat`が動作中のみ／再起動でURL変更）。常時稼働の固定URLが欲しい場合は GitHub Pages / Netlify / Vercel 等（各自ログインが必要）。

### インストール手順
- iOS(Safari)：共有ボタン →「ホーム画面に追加」
- Android(Chrome)：メニュー →「アプリをインストール／ホーム画面に追加」、または game内 設定 →「📲 ホーム画面に追加」
- ※ Service Worker は `https`／`localhost` でのみ動作（`file://`直開きは通常版として起動）。

### LAN直結（同じWi-Fiなら）
`python -m http.server 8765` → スマホで `http://<PCのIP>:8765`（※httpのためインストール/SWは制限あり）。

## 遊び方
1. **冒険** … 野生の原種と戦い、倒すとそのモンスターのパーツを1個ドロップ。
2. **組立** … 集めたパーツを11部位に割り当て、自分だけの **改造種** を生み出す。
3. **トレーニング** … ステータスを鍛える（対になるステータスが少し下がるトレードオフ）。
4. **図鑑 / 実績** … 原種500種・5系統をコンプリート。
5. **対人戦** … 改造種同士のAI対戦。

## 特徴（仕様）
- **原種500種**：ランク分布は SS1% / S5% / A10% / B19% / C25% / D40%（厳密体数で保証）。
- **5系統**：ドラゴン族(龍化)・機械族(機械)・魂蟲族(蠱毒)・古代族(古代)・天使族(神聖)。5すくみの相性。
- **無限の改造種**：パーツ（角/目/牙/耳/ボディ/腕/羽/爪/皮膚/足/尾）の組み合わせ。
- **ドット絵は手続き生成**：画像アセットなし。パーツ定義からCanvasに描画。系統×レアリティでパレットが変化。
- **ステータス**：HP/SP/攻撃/守備/素早さ/信頼(会心率)/運 ＋ 系統度合い(神聖/機械/龍化/蠱毒/古代)。
- **超必殺技**：系統度合いが閾値（例:龍化75）に達すると解禁。
- **ダメージはステータス依存（レベル非依存）**：攻撃と守備の比率型。会心は信頼、上振れは運に依存。
- **レアリティ**：敵が強いほど高レアの窓が開く（ドロップのレンジが上下）。

## 構成
```
index.html          … エントリ
css/style.css       … スタイル
js/rng.js           … シード付き乱数・分布
js/config.js        … 中央バランス設定
js/parts.js         … 11パーツ定義
js/names.js         … 名前生成
js/sprite.js        … ドット絵手続き生成
js/stats.js         … ステータス/度合い導出
js/skills.js        … 技・超必殺
js/species.js       … 原種500生成
js/monster.js       … モンスター組み立て
js/training.js      … トレーニング
js/battle.js        … バトルエンジン+AI
js/achievements.js  … 実績
js/save.js          … セーブ(localStorage)
js/game.js          … 中央コントローラ
js/ui.js            … 画面・演出
```
進行はブラウザのローカル保存に自動セーブされます。
